# Ubaidullah Portfolio — Final

## Run locally
1. Install Node.js
2. Open this folder in terminal
3. Run `node server.js`
4. Open `http://localhost:3000`

The design is a fresh final concept with 3D tilt interactions, animated particles, scroll progress, responsive layouts and a working Node.js contact endpoint.

## Admin Messages Dashboard
Open `http://localhost:3000/admin` after starting the server.

Default local login:
- Username: `admin`
- Password: `Ubaidullah@2026`

For a public deployment, set `ADMIN_USER` and `ADMIN_PASSWORD` environment variables to your own values before starting Node. Do not use the default password online.
